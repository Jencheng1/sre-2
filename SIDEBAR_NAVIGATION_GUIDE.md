# Sidebar Navigation Guide - SRE Copilot

## New Feature Location
The following features have been moved to the **sidebar** for better organization:

### 🛠️ Additional Tools Section
Located at the bottom of the sidebar after "Recent Incidents"

**Available Tools:**
1. **📋 Post-Mortem Analysis**
   - Generate comprehensive post-mortem reports
   - View historical reports
   - Analyze OpsItems

2. **🔐 IP Masking**
   - Mask sensitive IP addresses in logs
   - Configure masking settings
   - View masking statistics

3. **🧪 Test Scenarios**
   - Generate test incidents
   - Create custom scenarios
   - Run batch tests

## How to Access

1. **Look at the LEFT SIDEBAR** (not the main tabs)
2. Scroll down past:
   - Incident Management
   - Analyze Incident
   - Data Sources
   - Recent Incidents
3. Find **"🛠️ Additional Tools"** section
4. Select from dropdown:
   - None (default)
   - 📋 Post-Mortem Analysis
   - 🔐 IP Masking
   - 🧪 Test Scenarios
5. The selected tool will appear in the main area below the tabs
