# SRE Copilot Navigation Guide

## ✅ New Navigation System Active!

Due to Streamlit's tab display limitations, I've implemented a **3-group navigation system** to access all 11+ features.

### How to Navigate:

1. **Look for the navigation selector** below the main title
2. **Three navigation groups:**
   - 🏠 **Core Features** (5 tabs)
   - 🛠️ **Advanced Tools** (5 tabs) 
   - 📊 **Additional Features** (1-4 tabs)

### Navigation Groups:

#### 🏠 Core Features (Default)
1. 🚨 Incident Management - Generate real incidents
2. 🔍 Analyze Incident - Root cause analysis
3. 🔧 Recent Changes - Change tracking
4. 📚 Knowledge Base - Search knowledge
5. 📊 Analytics - Metrics and trends

#### 🛠️ Advanced Tools (Click to access)
1. 🐛 Defect Management - ALM/Jira integration
2. 🔗 Defect Correlation - AI correlation
3. 🧪 Correlation Scenarios - Test scenarios
4. **📋 Post-Mortem** - Generate reports ✨
5. **🔐 IP Masking** - Mask sensitive IPs ✨

#### 📊 Additional Features (Click to access)
1. **🧪 Test Scenarios** - Generate test incidents ✨
2. 🌐 MCP Status (if enabled)
3. 📈 Feedback Analytics (if enabled)
4. ❓ User Guide - Help documentation

## How to Access Post-Mortem, IP Masking, and Test Scenarios:

### For Post-Mortem (Tab 9):
1. Click **"🛠️ Advanced Tools"** in navigation
2. Click **"📋 Post-Mortem"** tab (4th tab)
3. Access all post-mortem features

### For IP Masking (Tab 10):
1. Click **"🛠️ Advanced Tools"** in navigation
2. Click **"🔐 IP Masking"** tab (5th tab)
3. Use IP masking tools

### For Test Scenarios (Tab 11):
1. Click **"📊 Additional Features"** in navigation
2. Click **"🧪 Test Scenarios"** tab (1st tab)
3. Generate test incidents
